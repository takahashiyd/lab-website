Tutorial

  1. Ajuste x₁, x₂, d ou aceite os defaults.
  2. Clique ▶ Forward — vê a ativação se propagar.
  3. Clique L para ver a perda calculada.
  4. Clique δ saída — δₖ aparece na saída.
  5. Clique δ ocultas — δⱼ aparece em cada oculta.
  6. Clique Atualizar pesos — vê os pesos mudarem (verde=↑, vermelho=↓).
  7. Repita ou use ⟳ Auto para treinamento contínuo.
