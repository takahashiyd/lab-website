O que esta simulação ensina: aqui você é o "professor" — cada ponto que você coloca é um exemplo rotulado. O modelo (regressão logística) aprende uma fronteira de decisão linear via gradiente descendente sobre a perda de entropia cruzada. Note: (i) se as classes se sobrepõem, o erro nunca chega a zero — é o limite irredutível dos dados; (ii) se você adicionar muitos pontos de um lado só, a fronteira "puxa" para acomodar; (iii) a taxa de aprendizado controla o quanto cada passo do gradiente desloca a fronteira — alta demais oscila, baixa demais converge devagar.

2 · Aprendizado não-supervisionado: k-means

Clique no canvas para adicionar pontos (sem rótulos!) ou carregue um exemplo. Escolha K (número de grupos), inicialize os centros e pressione Passo para ver uma iteração do algoritmo, ou Convergir para rodar até o fim. Cada iteração faz dois sub-passos: (1) atribuir cada ponto ao centro mais próximo, (2) mover cada centro para a média dos seus pontos.

Pontos cinza = sem atribuição  ·  Pontos coloridos = atribuídos ao centro daquela cor  ·  X = posição atual dos centros

O que esta simulação ensina: não há rótulos — você só fornece pontos, e o algoritmo descobre os grupos sozinho. Note: (i) a posição inicial dos centros importa — clique "Inicializar centros" várias vezes e veja como o resultado pode variar; (ii) o algoritmo sempre converge para um mínimo local da inércia (SSE), mas nem sempre é o melhor; (iii) se você escolher K=4 num conjunto com 2 grupos reais, o algoritmo vai forçar 4 grupos mesmo assim — escolher o K certo é uma tarefa difícil (ver cotovelo, silhueta). Esse é o algoritmo de Lloyd (1957/1982).

3 · Aprendizado por reforço: Q-Learning no gridworld

O agente parte do canto inferior esquerdo (azul) e precisa chegar ao objetivo (amarelo, +1) evitando o buraco (vermelho, −1). Cada passo custa −0.04. O algoritmo Q-Learning aprende o valor Q(s,a) — quanto vale tomar cada ação em cada estado. Use os controles para treinar e visualizar a política aprendida.

Setas pretas = política aprendida (melhor ação por estado)  ·  Cor de fundo do estado = valor máximo Q (verde = bom, vermelho = ruim)

O que esta simulação ensina: o agente nunca recebe a resposta certa — só recompensa escalar ao final de cada passo. Note: (i) com ε=0 o agente nunca explora e pode ficar preso; (ii) com ε muito alto ele explora demais e aprende devagar; (iii) γ próximo de 1 significa "valorizo recompensas distantes"; γ baixo, "só me importa o agora"; (iv) o retorno médio sobe ao longo do treino — é o sinal de que o algoritmo está convergindo. O Q-Learning (Watkins, 1989) é off-policy: aprende a política ótima mesmo enquanto explora aleatoriamente.
